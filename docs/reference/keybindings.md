## ⚡ Essential Shortcuts (Top 10)

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>?</kbd> | **Command Palette** | Open interactive help and keymap finder |
| <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> | **Cycle Panels** | Switch focus between side menu, list, and detail view |
| <kbd>j</kbd> / <kbd>k</kbd> | **Navigate Items** | Move selection down / up |
| <kbd>g</kbd> <kbd>m</kbd> | **Merge Requests** | Jump directly to Merge Requests view |
| <kbd>g</kbd> <kbd>i</kbd> | **Issues** | Jump directly to Issues view |
| <kbd>g</kbd> <kbd>b</kbd> | **Kanban Boards** | Jump directly to Sprint Kanban Boards |
| <kbd>g</kbd> <kbd>p</kbd> | **Pipelines** | Jump directly to CI/CD Pipelines |
| <kbd>p</kbd> | **Project Switcher** | Filter and quick-switch between GitLab projects |
| <kbd>/</kbd> | **Filter Search** | Search and filter active list items in real-time |
| <kbd>q</kbd> | **Quit** | Exit lazygitlab |
