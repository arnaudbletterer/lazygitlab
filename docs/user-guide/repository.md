# Repository Explorer & Files

Browse files, explore directory trees with syntax highlighting, and switch branches directly in your terminal.

---

## 🌲 Repository Tree & File Viewer (`g r`)

Navigate your project directory tree and inspect code files with high-speed syntax highlighting powered by `syntect`.

![Repository Tree & Syntax Highlighting](../assets/screenshots/repo_tree.svg#only-dark)
![Repository Tree & Syntax Highlighting (Light)](../assets/screenshots/repo_tree-light.svg#only-light)
*Click screenshot to expand in lightbox.*

### File Exploration Features:

* **Directory Traversal**: Press <kbd>Enter</kbd> to expand or collapse folders, or open files.
* **Syntax Highlighting**: Automatic language detection based on file extension and shebang headers.
* **Smooth Scrolling**: Navigate large code files using <kbd>j</kbd>/<kbd>k</kbd>, <kbd>Ctrl+D</kbd>/<kbd>Ctrl+U</kbd>, or <kbd>Page Down</kbd>/<kbd>Page Up</kbd>.
* **Switch Branch / Ref**: Press <kbd>b</kbd> to open the branch picker and switch repository refs instantly.

---

## 🔀 Project Quick Switcher (`p`)

Switch between any accessible GitLab project in seconds without restarting `lazygitlab`.

![Project Quick Switcher](../assets/screenshots/project_switch.svg#only-dark)
![Project Quick Switcher (Light)](../assets/screenshots/project_switch-light.svg#only-light)
*Click screenshot to expand in lightbox.*

* Filter projects instantly by typing any substring of group or project name.
* Press <kbd>Enter</kbd> to switch context immediately.

---

## Repository Shortcuts Cheatsheet

| Key | Action |
| --- | --- |
| <kbd>g</kbd> <kbd>r</kbd> | Go to Repository tree |
| <kbd>Enter</kbd> | Open directory / View file content |
| <kbd>b</kbd> | Open Branch Switcher popup |
| <kbd>p</kbd> | Open Project Quick Switcher |
| <kbd>j</kbd> / <kbd>k</kbd> | Scroll file content down / up |
| <kbd>Ctrl+D</kbd> / <kbd>Ctrl+U</kbd> | Page scroll half-screen down / up |
| <kbd>o</kbd> | Open file / repository in web browser |
| <kbd>Esc</kbd> | Return to repository tree navigation |
